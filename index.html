    Documentation & FAQ
    
        
      
    
      
    
        
        
    
          
    How It Works
    
          
    FormattingBuddy is a client-side document compiler designed to process long text and complex files cleanly:
    
          
    
            
    
              1. Local Ingestion & Cleaning
              
    Files are unpacked in background Web Workers. Headers, footers, page numbering, and line hyphenation are normalized automatically.
    
            
    
            
    
              2. Context-Aware Chunking
              
    Documents are sectioned into 1,500–2,500 word units at heading and page boundaries. Running summaries and heading lists ensure consistency.
    
            
    
            
    
              3. Visual Enrichments
              
    Processes become Mermaid diagrams; statistical data becomes Chart.js charts; location lists become Leaflet maps.
    
            
    
            
    
              4. Multi-Format Export
              
    Outputs are rendered to clean print-styled A4 PDF, styled Microsoft Word (.docx), offline self-contained HTML, or ZIP bundles.
    
            
    
          
    
        
    

        
        
    
          
    Supported File Formats
    
          
    Supports files up to 20 MB parsed entirely in your browser:
    
          
      
            
    • PDF (.pdf): Native text extraction with automatic scanned page detection.
      • 
            
    • Word (.docx): Converts headings, lists, tables, and styling directly into Markdown.
      • 
            
    • PowerPoint (.pptx): Extracts slide titles, speaker content, and bulleted outlines.
      • 
            
    • Excel & CSV (.xlsx, .xls, .csv): Formats worksheets as structured Markdown tables.
      • 
            
    • Text & Web (.txt, .md, .html, .json): Clean text parsing with tag stripping and JSON tree formatting.
      • 
            
    • Images (.png, .jpg, .jpeg, .webp): Processed via the Optical Character Recognition (OCR) engine.
      • 
          
    
          
    
            ⚠️ Legacy Formats: Older binary .doc and .ppt files are not supported directly. Please open them in Microsoft Office or LibreOffice and Save As .docx or .pptx before uploading.
          
    
        
    

        
        
    
          
    Security & Device Privacy
    
          
    FormattingBuddy has no backend, no server database, and zero analytics trackers:
    
          
      
            
    • Local Encryption: Your API keys are encrypted using Web Crypto AES-GCM (256-bit) with PBKDF2 key derivation.
      • 
            
    • Keys Never Leave Device: Keys are transmitted solely from your browser directly to the official endpoints of your chosen provider.
      • 
            
    • Offline Shell: The service worker caches all static assets, scripts, and libraries for complete offline availability.
      • 
          
    
        
    

        
        
    
          
    Optical Character Recognition (OCR)
    
          
    When scanned or non-searchable pages are detected, you can choose:
    
          
      
            
    • Fast & Private (Local): Uses Tesseract.js in a WebAssembly worker. Zero data leaves your computer. Supports English and Hindi.
      • 
            
    • Better Accuracy (AI Vision): Sends high-resolution page frames directly to Gemini 2.5 Flash for high-precision transcription.
      •
